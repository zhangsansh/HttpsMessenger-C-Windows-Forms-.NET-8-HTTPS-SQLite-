一、软件概述

HttpsMessenger 是基于 C# Windows Forms + .NET 8 开发的桌面软件， 主要面向教学实验、现场联调与 MES（制造执行系统）设备上位机对接场景。

软件同时具备两大能力域：

  1. HTTPS 通用通讯实验台：本机可作为 HTTPS 服务端与客户端，双向传消息， 展示 TLS/HTTP 全过程，支持自定义请求→响应字段规则（SQLite）。
  2. MES 生产接口客户端：按规范通过 HTTPS POST 提交表单参数 jsonData，覆盖登录、规格下发、上料、进站、组装、过站、三坐标、托盘条码等接口； 支持可配置路径、离线补传、上传成功后写 Excel 日志。
设计原则：Head/Body 分离、禁止把 JSON 拼到 URL；空值用 ""； 时间格式 yyyy-MM-dd HH:mm:ss；status=false 时把 result 报错提示给现场人员； 先上传成功，再写成功日志。

四、HTTPS 通讯使用方法

4.1 本机自测

  1. 启动程序，进入「HTTPS 通讯」。
  2. 确认端口（默认 8443），点击启动服务。
  3. 对端地址填 https://127.0.0.1:8443，勾选「忽略证书错误」。
  4. 点「测试连通」，或发送内容如 你好 / 帮助 / 时间 触发示例规则。
  5. 左侧看回复摘要，右侧看全部响应与全过程。

4.2 两机互发

  1. 双方均启动服务并放行防火墙端口。
  2. A 的对端填 https://B的IP:端口；B 同理填 A。
  3. 勿使用对方的 127.0.0.1。

4.3 字段规则

在「请求/响应字段规则」页管理规则。服务端收到消息后按规则写入响应 customFields。

  • 匹配方式：Equals / Contains / Any
  • 响应值占位符：{now}、{utc}、{machine}

五、MES 生产接口使用方法

5.1 本地模拟联调（推荐先试）

  1. 「HTTPS 通讯」页启动本机服务（8443）。
  2. 切到「MES 生产接口」，BaseUrl 设为： 
    https://127.0.0.1:8443/mes
  3. 勾选忽略证书错误，保存配置。
  4. 填写工号/密码/设备号/制令单/工序，点击登录。
  5. 登录成功后 SessionId 会显示；再选择业务接口点击调用接口。

5.2 对接真实 MES

  1. 将 BaseUrl 改为现场 MES 网关地址（仅主机+前缀，不含接口名）。
  2. 各接口 Path 可在 mes_config.json 修改（见第九章）。
  3. 正式证书环境可取消「忽略证书错误」。

5.3 离线补传

  1. 调用失败且为网络异常时，请求自动进入离线队列。
  2. 网络恢复后点「离线补传」批量重试。
  3. 补传成功后才写入 Excel 上传日志（与在线成功逻辑一致）。

5.4 生产 Excel

点击「打开生产Excel」进入目录：

%LocalAppData%\HttpsMessenger\production_logs\

按日文件：Production_yyyyMMdd.xlsx，含 UploadLog / ProductionData 工作表。

重要：成功日志仅在接口返回成功后写入，不会出现“未上传却已记成功日志”的情况。 当 status=false 时，弹窗展示 result 中的 MES 报错，请提示现场人员。

七、MES 接口清单与要点

1. LoginCheck — 设备登录

必填：userNo, passWord, deviceSn, moNumber, groupCode, timeStamp

成功时 result = SessionId，后续接口作为 operatorId 使用。

2. GetSpecifications — 生产规格参数下发

必填：groupCode, deviceSn, operatorId, moNumber, timeStamp

明细在 testResultDetails：paramCode/paramName/上下限/单位等。

3. MaterialControl — 产品上料校验

必填含 batchCode, assemblyNo, batchCount, loadItemFlag（1上料/2备料/3下料/4剩余量）

4. InStationCheck — 产品进站检查

必填：productSn 等；可选 IsAssemblySn（0组件/1否/2个体料）

成功明细可含 productMode：0首测 / 1复测

5. SubProductBinding — 半成品组装(配对)

productSn + productSnList[{subProductSn, position}]

6. ProductBinding — 半成品与成品绑定

成品条码 + 半成品列表 + groupCode + testResult(0=OK,1=NG)

7. GetTestData — 获取测试数据

sn + snType(cell/tray)

8. OutStationCheckData — 产品数据上传过站

含 testData / environment / stepData 集合；testResult：0=OK，1=NG

该接口成功后会额外写入 ProductionData Excel 明细。

9. GetCoordinateResult — 电芯三坐标挑选

snType=tray 批量 / cell 单颗；sorting 状态 0~3 见协议说明。

10. GetTaryBarcode — 获取托盘内电芯条码

输入 taryNo；返回 productSn、position、nextGroupCode。

8.1 HTTPS 服务端（HttpsChatServer）

  1. TcpListener 接受连接 → SslStream.AuthenticateAsServerAsync
  2. 按字节解析 HTTP 请求头与 Body（支持中文 Content-Length）
  3. 路由：/api/ping、/api/message、以及 MES Mock（如 /mes/LoginCheck）
  4. 过程写入 CommunicationTrace 供 UI 展示

8.2 MES 客户端（MesApiClient）

  1. 组装 URL = BaseUrl + 可配置 Path（路径可配，参数不进 URL）
  2. Body：jsonData=UrlEncode(json)
  3. Header：Content-Type / Accept / User-Agent 与 Body 分离
  4. 解析返回 JSON 为 MesApiResponse（status/result/...）

8.3 MesService 日志顺序

发送请求
  ├─ 网络失败 → 入离线队列（不写成功 Excel）
  ├─ status=false → 记 ERROR 日志 + 弹窗 result
  └─ status=true  → 记 INFO + 写 Excel（UploadLog / 可选 ProductionData）

十二、常见问题

Q1：MES 登录失败？

检查 BaseUrl、是否已启动本机模拟服务（本地联调）、证书忽略选项、工号/密码/设备号是否正确。看右侧响应 JSON 的 result。

Q2：为什么发送窗口只有两行摘要？

按需求设计：发送窗只显示回复信息；完整原始响应当看「全部响应信息」。

Q3：离线队列一直失败？

确认网络与 BaseUrl；达到 OfflineRetryMax 后需检查 LastError；可删除无效队列记录后重试。

Q4：Excel 没有记录？

仅成功上传后写入。失败或仅入离线队列时不会写成功日志；补传成功后会写。

Q5：JSON 解析错误？

勿从网页复制带 \n/\t 的脏字符；程序内用序列化器生成紧凑 JSON。空值用 ""。

Q6：端口被占用？

更换监听端口，并同步修改对端地址与 MES BaseUrl 端口。

Q7：顶部服务配置区为何不随窗口变？

按需求固定尺寸，保证控件完整可见；下方消息区仍可缩放拖分。
