软件运行环境要求清单

适用于 HttpsMessenger（含 MES 生产接口模块）现场部署与验收。

一、硬件环境

项目最低要求推荐配置
CPU双核 2.0GHz四核及以上
内存4 GB8 GB 及以上
硬盘500 MB 可用空间（含日志/Excel）SSD，预留 2 GB+
显示器1366×7681920×1080
网络可访问 MES 服务器 HTTPS 端口千兆有线，延迟 < 50ms

二、软件环境

项目要求
操作系统Windows 10/11（64 位）或 Windows Server 2019+
.NET 运行时.NET 8 Desktop Runtime（net8.0-windows）
开发/编译（可选）.NET 8 SDK
浏览器（查看帮助）Edge / Chrome 等现代浏览器

三、MES 通讯要求

  • 协议：HTTPS POST
  • 参数名：jsonData（UTF-8 JSON 字符串）
  • 提交方式：application/x-www-form-urlencoded 表单，禁止拼接到 URL
  • Head/Body 分离：HTTP Header 与 Body 独立，不允许 URL 拼接 jsonData
  • 时间格式：yyyy-MM-dd HH:mm:ss
  • 空值：使用 ""，不允许 null
  • 接口 BaseUrl 与各接口 Path 可在 %LocalAppData%\HttpsMessenger\mes_config.json 配置

四、本地数据与日志

类型路径
MES 配置%LocalAppData%\HttpsMessenger\mes_config.json
离线补传队列%LocalAppData%\HttpsMessenger\mes_offline.db
生产 Excel 日志%LocalAppData%\HttpsMessenger\production_logs\Production_yyyyMMdd.xlsx
运行日志%LocalAppData%\HttpsMessenger\logs\
SQLite 规则库%LocalAppData%\HttpsMessenger\https_messenger.db
日志原则：上传成功后才写入 Excel/成功日志；网络失败时进入离线队列，恢复网络后可补传过站数据。 status=false 时，result 为 MES 报错信息，程序会弹窗提示现场人员。

五、已实现的 MES 接口（11 个）

  1. LoginCheck — 设备登录
  2. GetSpecifications — 生产规格参数下发
  3. MaterialControl — 产品上料校验
  4. InStationCheck — 产品进站检查
  5. SubProductBinding — 半成品组装
  6. ProductBinding — 半成品与成品绑定
  7. GetTestData — 获取测试数据
  8. OutStationCheckData — 产品数据上传过站
  9. GetCoordinateResult — 电芯三坐标挑选
  10. GetTaryBarcode — 获取托盘电芯条码

六、本地联调（模拟 MES）

启动本机 HTTPS 服务（默认 8443），MES BaseUrl 设为：

https://127.0.0.1:8443/mes

本软件内置 MES 模拟响应，支持上述接口 form-urlencoded 测试。
